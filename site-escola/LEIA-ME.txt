SITE DA ESCOLA DE CONDUÇÃO S. CRISTÓVÃO
=======================================

1. Abra esta pasta no VS Code:  File > Open Folder...
2. Abra o terminal do VS Code:  Terminal > New Terminal
3. Na primeira vez, instale as dependências:
       npm install
4. Arranque o site:
       npm run dev
5. Abra no browser:  http://localhost:3000

O QUE EDITAR (procure a palavra PREENCHER)
   src/lib/dados.ts       contactos, horários, textos das cartas, dúvidas
   src/lib/precos.ts      todos os preços (incluindo os do simulador)
   src/lib/renovacao.ts   regras do simulador de renovação
   Grave o ficheiro e o site atualiza sozinho.

PÁGINAS DO SITE (pasta src/app)
   /            Início               src/app/page.tsx
   /cartas      Cartas               src/app/cartas/page.tsx
   /cartas/...  Uma página por carta src/app/cartas/[id]/page.tsx
   /precos      Preços               src/app/precos/page.tsx
   /horarios    Horários             src/app/horarios/page.tsx
   /renovacao   Renovação+simulador  src/app/renovacao/page.tsx
   /sobre-nos   Sobre nós            src/app/sobre-nos/page.tsx
   /duvidas     Dúvidas              src/app/duvidas/page.tsx
   /contactos   Contactos            src/app/contactos/page.tsx

Menu, rodapé, simulador e formulários: pasta src/components
Imagens: pasta public/escola

VERCEL: em Settings > Build and Deployment, o Framework Preset tem de ser
"Next.js" (o ficheiro vercel.json já trata disso).
