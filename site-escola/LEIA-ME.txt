SITE DA ESCOLA DE CONDUÇÃO S. CRISTÓVÃO
=======================================

VER O SITE NO COMPUTADOR
1. Abra esta pasta no VS Code:  File > Open Folder...
2. Terminal > New Terminal
3. Na primeira vez:  npm install
4. Depois:           npm run dev
5. Abra:             http://localhost:3000

MUDAR TEXTOS, CONTACTOS E SERVIÇOS
   src/lib/dados.ts   (grave e o site atualiza sozinho)

PUBLICAR O HORÁRIO DO MÊS
   Vá a  https://O-SEU-SITE/admin
   Escolha o mês (atual ou seguinte), o ficheiro (imagem ou PDF até 4 MB)
   e a palavra-passe. O horário aparece logo na página Horários.
   Ao mudar de mês, o site passa a mostrar sozinho o mês certo.

   Configuração única na Vercel (só na primeira vez):
   a) Storage > Create Database > Blob > ligar ao projeto
   b) Settings > Environment Variables > ADMIN_PASSWORD = (a sua palavra-passe)
   c) Deployments > Redeploy

PÁGINAS
   /            Início          src/app/page.tsx
   /horarios    Horários        src/app/horarios/page.tsx
   /sobre-nos   Sobre nós       src/app/sobre-nos/page.tsx
   /contactos   Contactos       src/app/contactos/page.tsx
   /admin       Publicar horário (não aparece no menu)
